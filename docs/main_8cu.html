Detailed Description

Entry point: runs GPU + CPU renderers, saves images, prints timing.

Menu-driven runtime config → build scene → run GPU kernel (primary rays) and CPU reference path, optional post-FX (GPU/CPU), save images (PPM/PNG), preview on Windows, print summary, and append CSV timings.

Design notes:

  • Keep device symbols local to this TU; host builds world and uploads once.
  • Determinism checks: FNV-1a CRC persisted per (scene,res,fx,seed) key.
