Detailed Description

CPU reference renderer: matches GPU scene/light/shader for visual parity.

Builds the scene on the host, traces primary rays + simple bounces, writes RGB (uchar3), and respects the same debug gizmos as the GPU path.

Design notes:

  • Host-only TU on purpose; no device constants/symbols pulled in.
  • I keep shading/shared math identical to the GPU to compare images 1:1.
  • Scene composition is bitmask-driven (Cornell | Spheres | Cubes).
