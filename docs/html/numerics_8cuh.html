Detailed Description

Small numeric helpers and constants (angles, tolerances, clamps).

Host/Device-friendly helpers for ray/geom math:

  • Tolerances and large/sentinel distances.
  • Angle conversions.
  • Clamp utilities and 8-bit normalization factors.
