Detailed Description

Camera definition and primary ray generation.

Simple pinhole camera and a helper to generate primary rays. Conventions:

  • Right-handed coordinates.
  • Default forward looks down −Z; +Y is up.
  • Pixel coords assume bottom-left origin (y = 0 at bottom). For top-left rasters, flip ndcY as noted in generatePrimaryRay().
