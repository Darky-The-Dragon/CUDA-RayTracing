Detailed Description

Console menu to build a RuntimeConfig (y/n booleans, defaults on Enter).

Interactive, minimal TUI that edits resolution, scene mask, debug flags, post-FX, and export settings, then returns a filled RuntimeConfig.

Design notes:

  • All parsing is tolerant: blank input keeps defaults; bad numbers fall back.
  • Number inputs clamp at call sites to keep ranges local/obvious.
  • Menus are small loops that return on empty input (Enter).
