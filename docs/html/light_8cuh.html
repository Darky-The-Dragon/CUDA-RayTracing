Detailed Description

Light source types and data structure.

Supports point, directional, and spotlight sources. The Light struct stores world-space position, direction, color, intensity, and other parameters used by shading for direct illumination, attenuation, and shadowing. Default ctor: white POINT light pointing downward.

enum LightType

Categories of light sources supported by the renderer.

  • POINT: Omnidirectional light from a position.
  • DIRECTIONAL: Parallel rays from a direction (e.g., sunlight).
  • SPOT: Cone-shaped light from a position + direction.
