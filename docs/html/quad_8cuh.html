Detailed Description

Quad primitive for ray tracing.

Axis-free quadrilateral defined by:

  • One corner position.
  • Two edge vectors (spanU, spanV).
  • A surface material. Surface: P(u,v) = position + u*spanU + v*spanV, with u,v in [0,1]. Notes:
  • spanU and spanV must not be colinear.
  • Normal uses right-hand rule: normalize(spanU × spanV). Used by both CPU and GPU rendering paths.
