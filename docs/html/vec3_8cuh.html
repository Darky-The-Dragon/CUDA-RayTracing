Detailed Description

Basic 3D vector type for points, directions, and colors.

Supports:

  • Common vector arithmetic (+, -, *, /)
  • Scalar and component-wise ops
  • Dot / cross products
  • Length and normalization Used for ray directions/positions, surface normals, and shading math.
