Detailed Description

Global configuration for active scenes and buffer limits.

Defines:

  • Scene selection bitmask flags (compose multiple scenes).
  • Default active scene mask.
  • Per-primitive buffer capacity limits for world build. Both CPU and GPU builds include this to keep scene composition identical.
