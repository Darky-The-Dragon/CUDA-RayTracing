Detailed Description

Centralized debug feature toggles (compile-time + runtime).

  • DebugConfig holds runtime flags (uploaded to device constant memory).
  • Compile-time macros act as upper bounds: if set to 0, the feature is compiled out even if runtime requests it.
  • Kernels should check both the DEBUG_DRAW_* macros and the runtime d_dbg.
