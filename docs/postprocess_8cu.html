Detailed Description

CPU & GPU post-processing (Gaussian blur, Bilateral filter).

Small, deterministic post-FX passes that run after raytracing. Implements:

  • Separable Gaussian blur (uchar3/uchar4)
  • Luma-guided Bilateral filter

Design notes:

  • I keep math identical across CPU/GPU to compare results 1:1.
  • Gaussian weights live in constant; bilateral uses constant tables.
