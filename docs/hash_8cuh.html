Detailed Description

Lightweight FNV-1a 32-bit checksum for reproducibility validation.

Implements the Fowler–Noll–Vo (FNV-1a) 32-bit hash algorithm for fast, architecture-independent checksums. Commonly used to validate image buffers or binary data consistency across CPU/GPU outputs.

Parameters

nNumber of bytes in the buffer.
Returns
32-bit checksum (deterministic across architectures).
Note
  • This implementation is host+device compatible (HD FINL).
  • The hash is reproducible across CPU/GPU runs and endian-safe.
  • Suitable for quick data validation, not cryptographic security.
