Detailed Description

Lightweight debug gizmos for visualizing light position and direction.

  • Small sphere at the light position (POINT/DIRECTIONAL/SPOT).
  • Short “arrow body” proxy indicating light direction (DIRECTIONAL/SPOT). Compile-time toggles live in debug_config.cuh; device checks also read d_dbg.
